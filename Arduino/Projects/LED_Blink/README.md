# LED Blink

This simple Arduino project blinks the board's built-in LED. It uses `LED_BUILTIN`, so no external LED or wiring is needed.

## Run the project

1. Open `LED_Blink.ino` in the Arduino IDE.
2. Select your Arduino board and its connected port.
3. Upload the sketch.

The built-in LED turns on for one second, then off for one second, and repeats.
